# 🧟 Zombi 777 Casino Bot

Телеграм-бот казино с Mini App в зомби-тематике. Поддержка оплаты Telegram Stars, система джекпота, ежедневные бонусы и админ-панель для управления выводами.

## ✨ Возможности

-   **7 уникальных игр:** Слоты, Кости, Монетка, Сейф (Джекпот), Рулетка, Краш, Мины
-   **Оплата Telegram Stars:** Автоматическое начисление игрового баланса после покупки
-   **Накопительный Джекпот:** 10% от каждой ставки в "Сейфе" идет в общий банк
-   **Ежедневный бонус:** 1 бесплатная попытка в игре "Кости" раз в 24 часа
-   **Система выводов:** Игроки создают заявки, админ подтверждает или отклоняет их прямо в Telegram
-   **Адаптивный Mini App:** Темный неоновый дизайн с анимациями и эффектами
-   **Локальная БД:** Хранение балансов, джекпота и заявок в JSON файле
